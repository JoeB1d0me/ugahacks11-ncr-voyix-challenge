# Grimoire Shop Inventory

## Overview ℹ️
> *Create a simple dashboard predicting stockouts and suggesting reorder timing addressing inefficient inventory management.*

Grimoire Shop Inventory is a full-stack inventory management dashboard that predicts stockouts and recommends optimal reorder timing.
Built for UGAHacks 11 – NCR Voyix Challenge.

This is my first ever submission for a hackathon and I'm happy to be able to share it with you all!

## Features
- Real-time inventory tracking
- Predictive stockout analysis
- Reorder recommendations
- Interactive charts
- CRUD management

## Tech Stack
- Flask (Backend)
- React (Frontend)
- SQLite (Database)
- Chart.js (Visualization)


## Installation & Running Locally
```bash
pip install flask flask-cors
python app.py
npm install

cd inventory-frontend
npm install
npm start

```
